# 六角學院切版作業：Nelson 部落格頁

六角學院課程的切版作業：依照課程提供的設計稿，切出設計師「Nelson」個人網站的「部落格」頁。

**線上預覽：<https://tsuwebber.github.io/hexschool-blog-layout/blog.html>**

## 內容

- 頁首導覽列（手機版收合成選單按鈕）
- 部落格 Hero Banner
- 左側分類列表 + 右側文章列表

這份作業只做了部落格這一頁，導覽列上的「服務項目」「專案作品」「與我聯絡」連到的頁面不在這個 repo 裡。

## 技術

- 純 HTML、CSS，沒有用框架
- `static/reset.css`：重置瀏覽器預設樣式
- `static/base.css`：顏色、字級、間距等共用工具 class
- `static/style.css`：這一頁的版面樣式
- 圖示：Bootstrap Icons、Material Symbols
- Logo 等素材取自六角學院課程提供的資源
